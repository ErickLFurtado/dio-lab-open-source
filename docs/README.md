## Sobre o Projeto
Projeto Desenvolvido durante BootCamp Bradesco Java cloud Native com a DIO. O objetivo é aplicar na prática a contribuição em um projeto open source, utilizando GitHub como plataforma de colaboração. O projeto prático foi feito especialmente para que qualquer pessoa que esteja iniciando na área tenha seu primeiro contato com um projeto real e colaborativo, experimentando na prática o que o open source pode proporcionar. <br>

## Sobre a DIO

A DIO é uma plataforma brasileira de educação digital que oferece cursos, bootcamps e desafios práticos em áreas como programação, desenvolvimento de software, análise de dados, cloud computing, entre outras. Ela é conhecida por colaborar com empresas e profissionais para capacitação em tecnologia, muitas vezes com foco em preparar os usuários para o mercado de trabalho.

## sobre o bootcamp
O <strong>Bootcamp do bradesco em parceria com a DIO</strong> é uma iniciativa que visa capacitar profissionais na área de técnologia. O objetivo é preparar os participantes para atuar no mercado de trabalho com projetos inovadores dentro do banco ou no mercado de técnologia em geral. <br>
Algumas das principais caracteristicas do bootcamp são: 

<li>Foco em Tecnologia</ul>
<li>Conteúdo Prático</ul>
<li>Gratuito</ul>
<li>Certificações</ul>
<br>


Para se inscrever basta acessar a plataforam da <a href="https://www.dio.me/">DIO</a> e procurar pelo bootcamp
